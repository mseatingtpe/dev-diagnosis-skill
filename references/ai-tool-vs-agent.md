# AI 工具 vs Agent 的差別

**差別不在於「有沒有多輪對話」，而在於「誰決定下一步做什麼」。**

- **AI 工具**：你給它一個輸入，它跑一次，給你一個輸出，結束。即使包裝成多輪對話的形式，每一步都是固定流程，跟填表單沒有本質差別。例如：你貼一段會議逐字稿，AI 產出摘要，完成。
- **Agent**：它會根據當下的情境，自己決定接下來要做什麼——去查資料、呼叫 API、改變提問方向、寫入紀錄。它的下一步不是事先寫好的腳本，而是根據它觀察到的東西動態決定的。例如：你說「我想做一個自動整理會議記錄的工具」，它自己去查既有 skill 清單、發現有半成品、改問你「這個現有的工具你試過嗎？」——這個轉向是它自己判斷的，不是寫在腳本裡的。

## 簡單的判斷方式

如果你能把整個流程畫成一張固定的表單或 checklist，每個人走的路徑都一樣 → 不是 Agent。如果流程會根據不同的輸入走出不同的路徑，而且中間需要去查東西、呼叫外部系統 → 是 Agent。
